## 🧬 Что это такое?

**Copyleft Auditor Pro** — десктопное приложение, которое сканирует репозиторий и отвечает
на два главных вопроса:

1. **Юридическая чистота** — какие лицензии лежат в коде, можно ли использовать его в коммерческом продукте,
   есть ли риск судебных исков.
2. **Безопасность кода** — не спрятана ли в репозитории обфускация, динамическое выполнение кода,
   опасные сигнатуры (сканер **Loki**).

Это **рентген для кода**: вы видите насквозь — баги, подозрительные паттерны, лицензионные мины.

## ⚡ Ключевые возможности

### 🛡 Юридический анализ
- **50+ определяемых лицензий**: GPL-2/3, AGPL-3.0, LGPL-2/2.1/3, MIT, Apache-2.0, BSD-2/3-Clause,
  MPL, EPL, CDDL, ISC, Unlicense, CC0-1.0, WTFPL, Public Domain и другие.
- Классификация лицензий: `copyleft_strong` / `copyleft_weak` / `permissive` / `public_domain`.
- Полный текст лицензий в отчете + выдержки из **README.md**.
- Поиск владельца авторских прав и года (паттерны `Copyright (c)`, `©`).
- **Юридический индекс здоровья** — оценка от 0 до 100 с грейдом (A–D).

### 🕵️ Обнаружение обфускации
Диагностируются 5 типов подозрительного кода:

| Тип | Что значит | Признаки |
|-----|------------|----------|
| `ПЕРЕИМ` | Переименование переменных | Короткие имена `_0x...`, `a`, `b` вместо нормальных |
| `МЁРТВ` | Мертвый код | `if(false)`, закомментированные блоки, лишний `return;` |
| `ВЛОЖЕН` | Вложенные условия | Глубокие вложенные `if` — попытка запутать логику |
| `КОДИР` | Кодированные строки | Base64, hex-строки 20+ символов |
| `СМЕШ` | Смешанная обфускация | Комбинация нескольких приемов |

**Опасные паттерны:** `eval()`, `Function()`, `exec()`, `system()`, `popen()`, `atob()`,
динамический импорт `__import__()`.

### 🔍 Сканер угроз Loki
- Интеграция с **Loki** (Neo23x0) — сканером IoC-сигнатур.
- Автоматическое обновление сигнатур с GitHub.
- Нахождение: криптомайнеры, веб-шеллы, трояны, подозрительные бинарники.

### 📦 Архивы
- Распаковка архивов **7-Zip**: `zip`, `7z`, `rar`, `tar`, `gz`, `bz2`, `xz`.
- Сканирование содержимого архивов без необходимости вручную распаковывать.

### 📄 Отчеты
- **Экспорт в HTML** — полноценный отчет, который сразу открывается в браузере.
- **Автосохранение** в папку `reports/` рядом с программой.
- Имя файла: `{репозиторий}_{дата-время}.html`.
- Вкладка **«Отчеты»**: список всех сохраненных отчетов, открытие, удаление, переход в папку.
- Код подозрительных файлов — только релевантные фрагменты ± 3 строки контекста,
  а не весь файл целиком.

### 🖥 Интерфейс
- Темная тема в стиле **синего киберпанка**.
- Две вкладки: `Сканирование` и `Отчеты`.
- Дерево файлов с подсветкой рисков `[OK]` / `[!]` / `[!!]`.
- Таблица детального анализа с цветовой маркировкой.
- Работает с локальным репозиторием **или** GitHub URL (автоклонирование).

## 🚀 Установка и запуск

### Требования
- Windows 10/11
- Python 3.10+
- [7-Zip](https://www.7-zip.org/) (для распаковки архивов)
- `git` (для клонирования GitHub-репозиториев)

### Из исходников

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Anton-18-PNG/CopyleftAuditorPro.git
cd CopyleftAuditorPro

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Запустите
python -m copyleft_auditor
```

### Самостоятельная сборка (PyInstaller)

```bash
# 1. Подготавливаем окружение
pip install --upgrade customtkinter markdown pyinstaller

# 2. Запускаем сборку
build.bat

# 3. Результат в папке dist\CopyleftAuditorPro\
```

## 🎯 Как пользоваться

1. **Укажите источник сканирования**: локальная папка репозитория или GitHub URL.
2. Нажмите **«Запустить сканирование»**.
3. Смотрите результат:
   - 🔴 **Красный** — файлы с обфускацией или угрозами, лицензии-копилефт, сигнатуры Loki.
   - 🟡 **Желтый** — средний риск, требует внимания.
   - 🟢 **Зеленый** — код чистый, лицензия в порядке.
4. **«Дерево файлов»** — визуальная карта репозитория с рисками.
5. **«Экспорт HTML»** — отчет сохраняется в папку `reports/` и сразу открывается в браузере.
